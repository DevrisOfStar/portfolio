# 개인정보 공개 범위

## 확정된 현재 정책

- 학력과 경력 데이터는 데이터베이스에 유지한다.
- 메인 화면의 경력 섹션과 경력 상세 화면에서는 학력과 경력을 표시하지 않는다.
- 이름, 이메일, GitHub, YouTube 등 `personal_info` 데이터는 공개 API 응답에 포함될 수 있다.

## 현재 API 상태

- `GET /api/portfolio` 응답에는 `career` 데이터가 포함된다.
- `GET /api/portfolio/career`는 인증 없는 공개 엔드포인트다.
- 따라서 학력과 경력은 일반 화면에서 숨겨져 있지만 API를 통해 조회할 수 있다.

## 미결정 사항

- 학력과 경력을 공개 API에서도 제거할지는 확정되지 않았다.
- 이 결정을 내리기 전에는 관련 API 응답을 임의로 변경하지 않는다.
- 공개 API에서도 비공개하기로 결정하면 전체 응답의 `career` 필드와 경력 전용 엔드포인트 처리 방식을 함께 정의해야 한다.

## 외부 서비스 고지

- `client/index.html`에서 사용하는 분석 또는 최적화 스크립트의 수집 항목, 목적, 보관 기간, 제3자 제공 여부는 아직 문서화되지 않았다.
- 공개 개인정보 처리방침 페이지 추가 여부와 고지 내용은 별도 정책 결정이 필요하다.
